# งานประจำวัน · หน้าเปิดระบบ (แอปที่ติดตั้งได้)

หน้าเว็บเล็กๆ ที่ทำให้ระบบลงงานประจำวันของ BLINGTASTIC STUDIO **ติดตั้งเป็นแอป** บนแท็บเล็ต Android (Chrome) ได้

- ระบบจริงเป็นเว็บแอปของ Google Apps Script ซึ่งใส่ไฟล์ประกาศแอป (web app manifest) ไม่ได้ — Chrome จึงให้แค่ "สร้างทางลัด"
- หน้านี้มี manifest + ไอคอน แล้วเปิดหน้าระบบไว้ข้างในเต็มจอ — ทุกอย่างทำงานที่หน้าระบบเหมือนเดิม หน้านี้ไม่เก็บและไม่ส่งข้อมูลงาน
- **ลิงก์ระบบไม่อยู่ในไฟล์ใดของ repo นี้** (repo สาธารณะ) — ตั้งครั้งเดียวต่อเครื่อง เก็บไว้ในเครื่องนั้นเท่านั้น

## ตั้งค่าแท็บเล็ต (ผู้ดูแล · ครั้งเดียวต่อเครื่อง)

1. เปิด Chrome บนแท็บเล็ต — ลงชื่อ Google ด้วยบัญชีที่ใช้กับระบบไว้ก่อน (บัญชีเดียวในเครื่อง)
2. เปิด **ลิงก์ตั้งค่า** ที่ผู้ดูแลส่งให้ (รูป `…/#exec=<ลิงก์ระบบ>`) — หรือเปิดหน้านี้แล้ววางลิงก์ระบบ (ลงท้าย `/exec`) ในช่อง
3. หน้าระบบขึ้นแล้ว → เมนู ⋮ ของ Chrome → **ติดตั้งแอป** → ได้ไอคอน "งานประจำวัน" บนหน้าจอและในหน้ารวมแอป
4. เปิดจากไอคอนนั้นทุกครั้ง · ระบบอัปเดต = ปิดแอปแล้วเปิดใหม่

ขึ้นว่า "ยังเปิดระบบไม่ได้" → แตะ **เข้าสู่ระบบ Google** (ลงชื่อด้วยบัญชีของระบบ แล้วปิดหน้าที่เปิดขึ้น) กลับมาที่แอป — หรือแตะ **ลองใหม่**

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเดียว: กรอบเต็มจอ + ข้อความรอ / ช่วยเหลือ (ไทย · พม่า) + หน้าตั้งค่าครั้งแรก |
| `app.js` | ลิงก์ระบบที่รับ (`/exec` · `/dev` ของ Apps Script เท่านั้น) · ลิงก์ตั้งค่า `#exec=` · รอข้อความ "เปิดได้แล้ว" จากหน้าระบบ |
| `manifest.webmanifest` · `icons/` | ข้อมูลแอปสำหรับ Chrome (ชื่อ · ไอคอน 192/512 แบบปกติและ maskable · เปิดแบบ standalone) |
| `sw.js` | เปิดหน้านี้ได้แม้เน็ตหลุด (ขึ้นข้อความแทนหน้าเออเรอร์ของ Chrome) |

แหล่งที่มาและเทสต์อยู่ใน repo ของระบบ (ส่วนตัว) — ไฟล์ที่นี่ถูกสร้าง/คัดลอกมาจากที่นั่น อย่าแก้ที่นี่โดยตรง
